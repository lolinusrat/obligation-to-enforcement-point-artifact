# Evidence

`manifest.csv` lists the first-party vendor documentation used in the
retrodiction study, with the URL and the date it was read.

**Snapshots are not redistributed here.** The documentation is the vendors'
copyrighted material and it changes; the manifest records what was read and
when, which is what a reader needs to check the coding or to observe that a
page has since moved. Every page was public and unauthenticated on the access
date.

**This dates the study, deliberately.** Vendor architectures change, and a
retrodiction result is a claim about documented practice at a point in time.
Anonymising the vendors would have removed the dating problem only by making the
evidence uncheckable.
